Ingeniero de Sistemas especializado en el desarrollo de aplicaciones web Full Stack. Cuento con experiencia sólida construyendo soluciones empresariales escalables con **Java (Spring Boot)** y **Angular**, aplicando **Arquitectura Hexagonal**, principios SOLID y metodologías ágiles (Scrum).
