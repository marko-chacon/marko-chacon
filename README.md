# ¡Hola! Soy Marko Chacón 👋

### Ingeniero de Sistemas | Desarrollador Full Stack & Arquitectura de Software

Ingeniero de Sistemas especializado en el desarrollo de aplicaciones web Full Stack. Cuento con experiencia sólida construyendo soluciones empresariales escalables con **Java (Spring Boot)** y **Angular**, aplicando **Arquitectura Hexagonal**, principios SOLID y metodologías ágiles (Scrum).

Paralelamente, soy creador y mantenedor de productos digitales independientes en producción (SaaS de facturación electrónica y aplicaciones móviles en Google Play Store).

## 🚀 Lo que hago

- 🏗️ **Arquitectura & Backend:** Diseño de APIs RESTful, microservicios y arquitectura limpia/hexagonal con Java Spring Boot, Laravel y Flask.
- 💻 **Desarrollo Frontend:** Construcción de interfaces dinámicas, responsivas y componentes de visualización de datos avanzadas (Angular, TypeScript, ECharts).
- 🗄️ **Bases de Datos Enterprise:** Modelamiento, optimización y gestión en PostgreSQL, Oracle, SQL Server y MySQL.
- 📱 **SaaS & Mobile:** Desarrollo e integración de plataformas en producción y apps móviles.
- 🤖 **Innovación & Datos:** Aplicación de Inteligencia Artificial mediante Machine Learning y Procesamiento del Lenguaje Natural (NLP).
